# 智能体开源与复现规范（智能体路线 · 必交）

选择智能体（Agent）或“工具调用 + 大模型”路线的队伍，**代码必须开源**（公开 Git 仓库，或提交可完整阅读与运行的源码包）。组委会同样执行：公开数据复现 → 私有评测集终评。

## 必交内容

| 项 | 要求 |
|----|------|
| 源码 | Git URL + **不可变 commit hash**，或完整源码 zip（含同一 hash 说明） |
| 许可证 | 仓库根目录 `LICENSE`；第三方依赖许可列表 |
| 任务声明与指标 | 同训练模型路线：`01`、`02`、公开预测文件 |
| 入口 | 批量推理/评测命令，对 `data_root` 下样本产出标准预测 CSV |
| 配置 | 示例 `config.example.yaml`（API Base、模型名、温度、最大轮数等）；密钥仅环境变量 |
| 运行日志 | 至少一份针对公开 test 抽样或全量的成功运行日志摘要（脱敏） |
| README | 环境、一键命令、硬件与耗时、限流/重试策略、联系人 |

## 推荐仓库结构

```text
agent_project/
  README.md
  LICENSE
  TASK_DECLARATION.md
  config.example.yaml
  requirements.txt          # 或 pyproject.toml，钉版本
  src/
    agent/                  # 编排、工具、提示词
    infer_batch.py          # 批量入口
  prompts/                  # 提示词模板，须入库
  metrics_public_test.csv
  predictions/
  logs/
    public_run_summary.md
```

## 批量入口约定

```bash
export LLM_API_KEY=***          # 勿写入仓库
python src/infer_batch.py \
  --data_root /path/to/data_root \
  --config config.example.yaml \
  --out /path/to/out/pred.csv
```

要求与模型路线相同：终评数据可能**无标签**；禁止依赖 test 标签；输出格式见 `03_预测结果格式.md`。

## 可复现性要求

- 固定 `temperature`、seed（若 API 支持）；在任务声明中写明。
- 提示词、工具列表、检索语料版本须纳入版本库；禁止“只存在于对话历史中的私有 prompt”。
- 若使用外部向量库/缓存，须提供可重建步骤或随包提供快照。
- 对 API 失败须有重试与限流；README 写明预算量级（token / 调用次数），便于组委会安排终评窗口。

## 密钥与安全

- 提交物与公开仓库中不得出现真实 API Key、网盘 cookie、SSH 私钥等。
- 组委会终评使用自有账号额度，或由队伍提供**可吊销、限额度**的密钥并在终评后作废。

## 与“训练模型”组合

若 Agent 依赖自研权重，须同时满足 `04_一键复现包规范.md`（权重 + 校验 + 可离线加载）。

不合格情形同 `06_评测与防造假协议.md`（无法开源完整运行、无批量入口、密钥写死、不可复现等）。
