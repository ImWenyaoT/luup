# 评价指标表模板（必填）

将下表另存为 `metrics_public_test.csv`（或直接按列填写后导出 CSV）随材料提交。
**每个「时间窗 × 正类/任务设定」一行。** 数值与预测文件经 `eval_metrics.py` 复算应一致。

## CSV 表头与示例行

```csv
team_name,task_id,horizon_hr,positive_class_def,label_column_or_mapping,threshold_rule,TP,FP,TN,FN,TSS,HSS,Precision,Recall_POD,F1,FAR,Accuracy,ROC_AUC,PR_AUC,notes
示例队,M1_24h,24,>=M1.0,flare_label_M1.0_24hr,val上最大化TSS,0,0,0,0,0.0000,0.0000,0.0000,0.0000,0.0000,0.0000,0.0000,,,公开test自评
```

## 列说明

| 列 | 含义 |
|----|------|
| team_name | 队名 |
| task_id | 与预测文件名、任务声明一致的短名 |
| horizon_hr | 预报时间窗（小时） |
| positive_class_def | 正类文字定义，如 `>=M1.0` |
| label_column_or_mapping | 公开 CSV 列名，或自定义映射说明 |
| threshold_rule | 阈值如何得到 |
| TP, FP, TN, FN | 混淆矩阵 |
| TSS, HSS | 必报 |
| Precision, Recall_POD, F1 | 必报（Recall 即 POD） |
| FAR, Accuracy | 必报 |
| ROC_AUC, PR_AUC | 有概率时建议报；无则留空 |
| notes | 备注（如：公开 test 自评） |

多分类：可先填宏/微 F1 于 notes，并**另起一行**写明折叠后的二分类 TSS/HSS。

指标定义见 `06_评测与防造假协议.md`。统一计算脚本见 `eval_metrics.py.md`（落地为 `.py` 后即可运行）。
