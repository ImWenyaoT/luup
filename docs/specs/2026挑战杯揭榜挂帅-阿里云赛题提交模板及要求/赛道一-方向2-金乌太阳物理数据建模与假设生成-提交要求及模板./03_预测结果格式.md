# 预测结果提交格式

用于**公开 test 初评复核**。私有终评时，组委会使用同一推理入口对私有数据目录生成预测，格式应保持一致。

## 文件命名

```text
predictions__{task_id}.csv
```

示例：`predictions__M1_24h.csv`。`task_id` 须与《任务定义声明》及评价指标表中的 `task_id` 一致。多任务则多文件。

## 二分类（或已折叠为二分类）

表头：

```text
image_filename,probability,prediction
```

| 列 | 要求 |
|----|------|
| `image_filename` | 与公开 test CSV 中 `image_filename` 完全一致，例如 `AR3767_20240726_000000.png` |
| `probability` | 正类概率，`[0,1]`；若模型无概率，可留空或填与 `prediction` 相同的 0/1，并在声明中说明 |
| `prediction` | `0` 或 `1`（整数） |

- 行集合应覆盖公开 test 全部样本（缺行视为无效提交）；允许顺序不同，组委会按 `image_filename` 对齐。
- `prediction` 所用阈值须与指标表 `threshold_rule` 一致。

## 多分类

表头示例：

```text
image_filename,pred_label,prob_0,prob_C,prob_M,prob_X
```

- `pred_label` 取值须与任务声明中的类别列表一致。
- 概率列可选但推荐；列名与类别一一对应。
- 另须能按声明中的**折叠规则**生成二分类 `prediction`，或额外提交一份已折叠的二分类预测文件，以便计算 TSS/HSS。

## 校验建议（提交前）

```bash
# 将 eval_metrics.py.md 中源码保存为 eval_metrics.py 后：
python eval_metrics.py \
  --labels /path/to/JW-FD_subset/label/png/Th1000/solar_flare_dataset_png_Lat60_Lon60_Th1000_test.csv \
  --preds predictions__M1_24h.csv \
  --label-col flare_label_M1.0_24hr \
  --id-col image_filename
```

指标应与 `02_评价指标表模板.md` 导出表中对应行一致（浮点误差在 1e-4 量级内可接受）。
