# 一键复现包规范（训练模型路线 · 必交）

组委会需能在约定机器上**夜间无人值守**完成：环境就绪 → 加载权重 → 对指定 `data_root` 推理 → 写出标准预测 CSV。公开复现通过后，将 `data_root` 换为私有评测集做终评。

## 推荐目录结构

```text
submission_bundle/
  README.md                 # 必读：一键命令、硬件、耗时、联系人
  TASK_DECLARATION.md       # 或 PDF：填写后的任务定义声明
  metrics_public_test.csv   # 公开 test 指标表
  predictions/              # 公开 test 预测 CSV
  checksums.txt             # 权重与关键大文件 SHA256
  env/
    Dockerfile              # 推荐
    environment.yml         # 或 requirements.txt（钉死版本）
  weights/                  # 或 README 中给出可校验的下载方式
    model.pt
  code/
    infer.py                # 唯一推荐推理入口（名称可改，但 README 必须写死命令）
    train.py                # 可选；终评不依赖重新训练
    ...
  third_party_licenses.md   # 第三方与许可证
  run_reproduce.sh          # 一键脚本（见下）
```

## 推理入口约定

`README.md` 中必须给出**可复制**的一条（或一组固定）命令，例如：

```bash
./run_reproduce.sh /path/to/data_root /path/to/out_dir
```

或：

```bash
python code/infer.py --data_root /path/to/data_root --out /path/to/out_dir/pred.csv
```

要求：

- `--data_root`（或等价参数）指向数据集根目录；其下布局与公开包一致时，应能直接找到图像与（若需要）特征；**终评时目录中可能无标签文件，推理不得依赖 test 标签。**
- 输出为 `03_预测结果格式.md` 规定的 CSV。
- 不得在推理阶段联网下载权重（权重须已在包内或镜像内）；允许的例外仅限组委会书面批准的模型托管地址，且须校验哈希。

## `run_reproduce.sh` 最小示例

```bash
#!/usr/bin/env bash
set -euo pipefail
DATA_ROOT="${1:?data_root required}"
OUT_DIR="${2:?out_dir required}"
mkdir -p "$OUT_DIR"
python code/infer.py --data_root "$DATA_ROOT" --out "$OUT_DIR/pred.csv"
```

使用 Docker 时，在 README 写明：

```bash
docker pull <image>@sha256:<digest>
docker run --gpus all -v "$DATA_ROOT":/data:ro -v "$OUT_DIR":/out <image> \
  python infer.py --data_root /data --out /out/pred.csv
```

## README 必含检查清单

- [ ] 队名、任务 `task_id`、联系人与响应窗口
- [ ] 硬件：GPU 型号建议、显存、内存、磁盘
- [ ] 公开 test 全量推理预计墙钟时间
- [ ] 环境安装或拉镜像步骤（无交互）
- [ ] 权重路径与 `checksums.txt` 中哈希一致
- [ ] 一键推理命令
- [ ] 已知限制（CPU-only 不可用、需特定 CUDA 等）

## 不合格情形（摘要）

- 仅有训练代码、无法直接推理
- 权重缺失或哈希不符
- 推理依赖测试标签或写死本机绝对路径且不可配置
- 需人工逐步点选、交互式 notebook 才能出结果
- 超过组委会公布的推理时限仍未产出合法 CSV

细则与容差见 `06_评测与防造假协议.md`。
