# Hypotheses: How are pulsars formed?

## H1
- **假设陈述**: 脉冲星（含磁星）主要通过大质量恒星核心坍缩超新星爆发形成；若前身星群体的演化模型所预测的诞生率无法维持当前观测到的脉冲星数量，则该标准形成通道模型需要修正。
- **推导链**:
  1. [F3] 归纳 → 年轻脉冲星 PSR B1509-58 位于超新星遗迹 MSH 15-52 中心，证实脉冲星与超新星遗迹存在空间关联。
  2. [F4] 归纳 → 磁星 1E 1841-045 同样位于超新星遗迹 Kes 73 中心，表明磁星（脉冲星的极端磁场成员）也与超新星遗迹成对出现。
  3. [F9] 演绎 → 脉冲星风星云在伽马射线波段的广泛存在，说明年轻脉冲星在超新星爆发后持续充当遗迹的中心引擎——这与核心坍缩形成场景一致。
  4. [F8] 演绎 → 银河系超新星产生的中微子可被探测，为核心坍缩过程提供直接探针，进一步支持中子星经由核心坍缩诞生的标准模型。
  5. [F1] 演绎 → 任何演化模型（包括核心坍缩场景）必须通过的关键测试是：前身星群体能否维持观测到的脉冲星诞生率。
  6. 结论 → 核心坍缩超新星是脉冲星的主要形成通道，但该模型必须接受诞生率一致性检验；若检验失败，则标准模型需修正。
- **预期新颖性**: 将空间关联证据（F3、F4）、中心引擎证据（F9）与诞生率约束（F1）整合为一个可定量检验的统一框架，而非仅定性断言"脉冲星来自超新星"。
- **可证伪点**: 若精确的前身星群体模型（如基于初始质量函数与恒星形成率）预测的核心坍缩率显著低于观测到的脉冲星诞生率，则此假设的标准通道主导图景被推翻。

## H2
- **假设陈述**: 脉冲星/磁星的形成并非仅由核心坍缩超新星单一通道完成；白矮星合并与吸积诱导坍缩等替代通道对致密天体群体有不可忽略的贡献，且这些通道在空间密度上留下可区分的印记。
- **推导链**:
  1. [F5] 归纳 → 毫秒自旋磁星与快速 X 射线暂现源（FXTs）的空间密度比较揭示了致密天体形成通道的多样性，明确提及白矮星合并或吸积诱导坍缩作为可能的替代通道。
  2. [F7] 归纳 → 费米伽马射线源射电巡天发现的多颗毫秒脉冲星被认为是双星系统中通过吸积再循环形成的——这是有别于标准核心坍缩的另一形成/演化路径。
  3. [F6] 演绎 → P-Pdot 图作为脉冲星研究基石，其传统可视化方法在揭示形成与演化全貌方面存在局限，暗示形成机制的复杂性超出单一通道模型所能解释的范围。
  4. 结论 → 至少存在两条独立形成通道（核心坍缩超新星 + 合并/吸积诱导坍缩），且它们在空间密度与周期-周期导数分布上应留下可区分的统计印记。
- **预期新颖性**: 将 F5 提出的替代通道从"可能性"提升为"对群体统计有可观测贡献"的定量假设，并与 F7 的双星再循环通道统一为多通道形成图景。
- **可证伪点**: 若未来大样本巡天表明所有脉冲星（含毫秒脉冲星与磁星）的空间密度分布均可由单一核心坍缩通道（考虑动力学演化后）完美拟合，且不存在需要额外通道才能解释的密度过剩区域，则此多通道假设被推翻。

## H3
- **假设陈述**: 中子星诞生时经历的磁旋转不稳定性（导致自转周期增加、磁场指数衰减）是决定其初始物理状态的关键过程；该不稳定性参数的不同初始条件可以统一解释普通脉冲星与磁星在 P-Pdot 图上的分化。
- **推导链**:
  1. [F2] 演绎 → 中子星诞生时可能经历磁旋转不稳定性，引发三个物理变化：自转周期增加、磁场指数衰减、动能与辐射能变化——这为从初始状态到当前观测状态的演化提供了物理机制。
  2. [F4] 归纳 → 磁星作为脉冲星家族中具有极端磁场特性的成员，位于超新星遗迹中心，说明其与普通脉冲星共享同一类形成事件（核心坍缩），但物理参数极端不同。
  3. [F6] 演绎 → P-Pdot 图用于分类群体和理解演化轨迹，但传统方法存在局限——暗示需要额外的物理参数（如磁旋转不稳定性的初始条件）来解释群体分布。
  4. [F3, F9] 归纳 → 年轻脉冲星（如 PSR B1509-58）及其风星云的高能辐射证实了脉冲星诞生后持续注入能量的过程，这与 F2 所述的诞生时能量变化机制一致。
  5. 结论 → 磁旋转不稳定性的初始参数（如初始磁场强度与自转速率的组合）是决定一颗新生中子星演化为普通脉冲星还是磁星的关键变量；若该假设正确，则在 P-Pdot 图上应存在由该不稳定性参数决定的连续演化轨迹，连接两类天体。
- **预期新颖性**: 将 F2 提出的诞生时磁旋转不稳定性从"加速机制"推广为"脉冲星-磁星分化的统一判据"，为 P-Pdot 图上的群体分布提供物理解释。
- **可证伪点**: 若在年轻脉冲星群体中找不到磁旋转不稳定性所预言的周期增加与磁场衰减的统计趋势（例如通过独立年龄估计与磁场强度的相关性分析），或磁星与普通脉冲星在 P-Pdot 图上呈现完全分离、无过渡区域的分布，则此统一分化假设被推翻。
