# 候选假设

## H1
- **假设陈述**: 脉冲星群体中存在一个由电子捕获超新星（EC SN）产生的子群，该子群的空间速度系统性地低于整体平均诞生速度（250–300 km/s），且其前身星质量集中在 6.5–12 M☉ 范围内。
- **推导链**:
  1. [F3] 归纳 → 电子捕获超新星的前身星为 6.5–12 M☉ 的超渐近巨星支（super-AGB）恒星，构成一条独立的中子星形成通道。
  2. [F4] 演绎 → 该通道产生的中子星获得显著低于典型中子星的出生 kick 速度。
  3. [F7] 演绎 → 整体脉冲星平均诞生速度为 250–300 km/s；若 EC SN 通道的 kick 显著更低，则其产物速度应系统性低于此平均值。
  4. 结论 → 综合 F3 的质量约束与 F4+F7 的速度约束，可预言一个低速度、窄前身星质量范围的脉冲星子群。
- **预期新颖性**: 将独立的 EC SN 理论通道与可观测的脉冲星运动学特征直接挂钩，提供区分不同形成通道的方法。
- **可证伪点**: 若在完整脉冲星样本中找不到速度系统性低于 ~200 km/s 且质量/前身星特征与 super-AGB 恒星一致的子群，或低速度脉冲星的前身星质量分布与 6.5–12 M☉ 无显著关联，则该假设被推翻。

## H2
- **假设陈述**: 白矮星吸积诱导坍缩（AIC）产生的中子星构成观测到的磁星或毫秒脉冲星的一个可识别子群，其旋转周期、偶极磁场强度和表面热特征与广义相对论磁流体力学（GRMHD）模拟所预言的 AIC 残骸性质一致。
- **推导链**:
  1. [F8] 归纳 → 磁化白矮星的 AIC 在理论上可作为毫秒脉冲星的起源通道，坍缩前自转演化可被计算。
  2. [F10] 演绎 → 九组轴对称 GRMHD 模拟已给出 AIC 残骸的旋转、磁场和热结构的定量预言，提供了可对照的观测特征模板。
  3. [F9] 演绎 → AIC 事件因放射性镍产量极少而光学信号暗淡，至今未被直接探测；因此不能依赖瞬态信号确认，而应在已有脉冲星群体中寻找与 AIC 残骸模板匹配的"化石"证据。
  4. 结论 → 若 AIC 确实发生，则当前脉冲星/磁星样本中应存在性质与 F10 模拟预言一致的对象。
- **预期新颖性**: 提出通过已有脉冲星群体的性质匹配来间接确认 AIC 通道，绕过直接探测 AIC 瞬态信号的困难。
- **可证伪点**: 若在磁星或毫秒脉冲星样本中找不到任何对象的旋转周期、磁场强度和热特征同时落入 F10 模拟参数空间内，或 AIC 残骸的参数空间与所有已知脉冲星性质完全不重叠，则该假设被推翻。

## H3
- **假设陈述**: 磁星存在两条可区分的形成通道——原中子星内部湍流对流发电机（慢旋转、强磁场）和 fallback 吸积驱动的 Tayler-Spruit 发电机（快旋转、超强磁场）——两条通道在观测上表现为磁星群体的旋转周期与磁场强度的双峰分布。
- **推导链**:
  1. [F5] 归纳 → 原中子星内部湍流对流发电机可产生磁星级偶极磁场，该机制不要求原中子星快速旋转。
  2. [F6] 归纳 → fallback 吸积使原中子星快速旋转并通过 Tayler-Spruit 发电机放大出超强磁场，该机制要求快速旋转作为前提。
  3. [F5, F6] 演绎 → 两条机制对初始旋转的要求不同（F6 需要 fallback 加速，F5 不依赖快速旋转），因此产生的磁星在旋转周期上应有系统性差异。
  4. 结论 → 磁星群体应呈现旋转周期–磁场强度的双峰结构：一组为对流发电机产生的较慢旋转磁星，另一组为 fallback 通道产生的较快旋转、更强磁场磁星。
- **预期新颖性**: 将两种理论上的磁星发电机机制转化为可通过磁星群体统计检验的可证伪预言。
- **可证伪点**: 若磁星样本的旋转周期与磁场强度呈现单峰连续分布而非双峰结构，或快旋转磁星与慢旋转磁星在其他可观测性质（如宿主环境、年龄）上无系统差异，则该双通道假设被削弱或推翻。
