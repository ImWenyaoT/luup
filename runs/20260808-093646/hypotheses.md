# 候选假设：How are pulsars formed?

## H1
- 假设陈述: 新生脉冲星的反冲速度（kick velocity）与其前身星核心坍缩时的磁场强度呈正相关关系。
- 推导链:
  1. [F5] 演绎 → 强磁场导致中子星形成过程中镜像对称性破缺，产生不对称的中微子通量
  2. [F6] 演绎 → 各向异性中微子发射是观测到的脉冲星自行（反冲速度）的来源
  3. [F1] 演绎 → 中微子沉积能量是驱动超新星爆发和形成新生中子星的关键机制
  4. 归纳 → 综合以上：前身星核心磁场越强 → 中微子发射越不对称 → 脉冲星反冲速度越大
  5. 结论 → 脉冲星反冲速度与前身星核心磁场强度正相关
- 预期新颖性: 将脉冲星运动学特征与其前身星物理条件直接关联，提供可观测检验的定量预测
- 可证伪点: 若观测发现强磁场脉冲星与弱磁场脉冲星的平均反冲速度无显著差异，或呈负相关，则推翻此假设

## H2
- 假设陈述: 脉冲星的诞生性质（质量、自转、磁场）主要由前身星的包层质量决定，而非由核心坍缩过程中的随机涨落主导。
- 推导链:
  1. [F10] 演绎 → 核心坍缩超新星观测显示多样性中的规律性，包层质量是爆炸的驱动参数之一
  2. [F1] 演绎 → 脉冲星形成于大质量恒星的坍缩与超新星爆发
  3. [F2] 演绎 → 中子星诞生性质目前主要从理论预测，观测数据不足以约束
  4. 归纳 → 若包层质量驱动超新星多样性（F10），且脉冲星形成于此类超新星（F1），则包层质量应系统性地影响脉冲星诞生性质
  5. 结论 → 脉冲星诞生性质由前身星包层质量系统性决定
- 预期新颖性: 提出脉冲星诞生性质的主要决定因素是可观测的前身星参数，而非不可预测的坍缩物理
- 可证伪点: 若未来观测发现相同包层质量的前身星产生的脉冲星在质量、自转、磁场上呈现大范围随机分布，则推翻此假设

## H3
- 假设陈述: 毫秒脉冲星的形成需要独立于普通脉冲星的演化通道（双星吸积），而非普通脉冲星演化的自然延续。
- 推导链:
  1. [F7] 演绎 → 毫秒脉冲星形成需要满足最小吸积率条件；低于此值则无法形成
  2. [F1] 演绎 → 普通脉冲星形成于大质量恒星坍缩与超新星爆发
  3. [F10] 演绎 → 核心坍缩超新星性质显示连续性和规律性
  4. 归纳 → 若毫秒脉冲星需要特殊的双星吸积条件（F7），而普通脉冲星来自单星坍缩（F1），且单星坍缩具有连续性（F10），则毫秒脉冲星不能是普通脉冲星演化的简单延续
  5. 结论 → 毫秒脉冲星需要独立的双星吸积形成通道
- 预期新颖性: 明确区分两类脉冲星的形成机制，预测它们在前身星系统和演化历史上存在本质差异
- 可证伪点: 若发现毫秒脉冲星可以来自单星演化（无伴星历史），或发现普通脉冲星与毫秒脉冲星之间存在平滑过渡的中间群体，则推翻此假设
