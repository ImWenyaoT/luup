# 候选假设

## H1
- **假设陈述**: 宇宙线从银河系源主导到河外源主导的过渡发生在"膝"（~4 PeV）到"踝"之间的能区：膝以下由超新星遗迹（SNR）加速贡献为主，而超高能端（> EeV）由伽马射线暴（GRB）或引擎驱动超新星等河外暂现源加速贡献为主。
- **推导链**:
  1. [F1] 归纳 → SNR 通过扩散激波加速是银河系宇宙线的主要候选加速源，其加速能力存在能量上限。
  2. [F6] 演绎 → 能谱在 ~4 PeV 处存在"膝"结构，可能与质子成分的截止有关——这暗示银河系 SNR 加速的质子成分在此能量附近达到极限。
  3. [F5] 归纳 → GRB 和引擎驱动超新星被认为是超高能宇宙线的潜在加速源，其加速能力远超 SNR。
  4. [F3] 演绎 → Auger 在 >8 EeV 观测到大尺度偶极各向异性，表明该能段宇宙线具有河外起源，与 SNR 的银河系图像不一致。
  5. [F2] 归纳 → UHECR（>5 EeV）以重核为主并存在高能抑制，这与 SNR 加速质子为主的图像不同，却与 GRB/引擎驱动超新星的加速条件相容。
  6. 结论 → 存在一个从 SNR（银河系）到 GRB/引擎驱动超新星（河外）的源主导过渡，过渡能区位于膝到踝之间。
- **预期新颖性**: 将膝区质子截止（F6）与超高能偶极各向异性（F3）统一为同一"源过渡"图像的两端观测表现。
- **可证伪点**: 若在膝到踝能区（~10^15–10^18 eV）的成分测量显示该区间仍以 SNR 可加速的轻核为主且各向异性指向银河系盘面，则过渡图像不成立；反之，若该区间已出现重核主导且各向异性指向河外大尺度结构，则支持该假设。

## H2
- **假设陈述**: "膝"结构（~4 PeV）并非所有银河系加速源共同达到能量上限的普遍截断，而是由一个或少数几个邻近暂现源（如近期超新星遗迹或 GRB 余辉）对局部宇宙线通量的主导贡献所造成。
- **推导链**:
  1. [F6] 归纳 → "膝"的形成可能与单一源的贡献有关，而非仅仅是质子截止。
  2. [F9] 演绎 → 膝区能谱表现出对时间和空间的依赖性，可能受少数邻近暂态源影响，这直接挑战了均匀扩散与稳态源的传统假设。
  3. [F1] 归纳 → SNR 是离散、瞬态的事件，不同 SNR 的年龄和距离不同，对局部宇宙线通量的贡献具有时变性。
  4. [F10] 演绎 → 银河系内宇宙线传播涉及复杂扩散、对流与再加速，意味着邻近源的贡献不会被完全均匀化。
  5. 结论 → "膝"可能反映的是太阳系附近少数邻近暂现源在特定能段的贡献峰值或截止，而非银河系全体 SNR 的集体加速极限。
- **预期新颖性**: 用"邻近暂现源主导"替代"全局加速极限"来解释膝结构，将膝从源物理问题转化为传播与源分布的局部效应问题。
- **可证伪点**: 若未来高精度各向异性测量（如 LHAASO、TA）显示膝区宇宙线到达方向均匀分布于全天、且能谱形状在不同天区一致，则"少数邻近源主导"假设被削弱；反之，若膝区能谱在不同方向呈现显著差异或存在可识别的点源 excess，则支持该假设。

## H3
- **假设陈述**: 超高能宇宙线中重核的主导成分（F2）与 >8 EeV 偶极各向异性（F3）共同表明，GRB/引擎驱动超新星是 UHECR 重核的主要加速源，且这些源的空间分布追踪了邻近宇宙的大尺度结构。
- **推导链**:
  1. [F2] 归纳 → UHECR 以重于质子的原子核为主，且极高能端存在强抑制——加速源必须能有效加速重核并存在最大刚度的截断。
  2. [F5] 演绎 → GRB 和引擎驱动超新星具有极端物理条件（高磁场、高洛伦兹因子），能够加速重核到 UHECR 能量；其伴随的 TeV 光子延迟发射（F5 报道）提供了多信使检验手段。
  3. [F3] 归纳 → >8 EeV 的偶极各向异性表明 UHECR 并非完全随机分布，而是追踪了河外源的大尺度分布。
  4. [F8] 演绎 → Auger 对最高能宇宙线的长期观测提供了能谱和到达方向的精确测量，为将成分与各向异性联合分析提供了数据基础。
  5. [F4] 归纳 → 核成分鉴别和到达方向重建是当前实验的关键挑战，意味着成分-各向异性的联合分析需要谨慎处理系统误差。
  6. 结论 → 若 GRB/引擎驱动超新星是 UHECR 重核的主源，则重核成分的比例应随能量变化并与偶极各向异性的幅度相关联：在抑制能区附近，各向异性幅度应因源密度下降而增大。
- **预期新颖性**: 将重核成分演化（F2）与偶极各向异性（F3）作为同一物理起源（GRB/引擎驱动超新星）的两个可联合检验的观测预言。
- **可证伪点**: 若在 >8 EeV 能区发现 UHECR 成分以质子为主（而非重核），或偶极各向异性的指向与已知大尺度结构（如本地超星系团）完全无关，则该假设被证伪；反之，若重核比例与偶极幅度在抑制能区呈现正相关演化，则构成强支持。
