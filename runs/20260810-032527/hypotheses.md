# 候选假设 — How are pulsars formed?

## H1
- **假设陈述**: 若磁星通过 Tayler-Spruit 发电机机制形成，则磁星群体的磁场强度与自转周期之间应呈现反相关关系（即更强磁场对应更慢自转），且该统计趋势显著区别于普通射电脉冲星群体。
- **推导链**:
  1. [F6] 归纳 → 磁星的形成通道至今仍是未解之谜，存在知识缺口。
  2. [F10] 演绎 → Tayler-Spruit 发电机机制被提出作为磁星形成的候选场景；该机制的本质是在原中子星内部将旋转动能转化为磁能。
  3. [F2] 演绎 → 中子星的诞生属性包含自转和磁场两个可观测量，二者可被联合统计。
  4. 若发电机机制将旋转能转化为磁能（步骤2），则旋转越慢→可转化能量越少→磁场越弱，反之亦然；因此该机制预言 B 与 P 呈反相关（中间结论）。
  5. 结论 → 在磁星样本中应观测到磁场强度与自转周期的反相关趋势，且该趋势在普通脉冲星中不显著。
- **预期新颖性**: 首次将 Tayler-Spruit 发电机机制转化为可在 P–Ṗ 平面上被直接证伪的群体统计预言，绕过 F6 所指出的"通道不明"困境。
- **可证伪点**: 若未来磁星样本（含新发现样本）显示 B 与 P 无显著反相关，或该反相关趋势与普通脉冲星群体无统计差异，则 Tayler-Spruit 发电机作为磁星主导形成通道的假设被推翻。

## H2
- **假设陈述**: 吸积诱导坍缩（AIC）形成的中子星在自转周期–磁场–表面热结构三维参数空间中占据一个与普通核心坍缩脉冲星及再循环毫秒脉冲星均不重叠的独立区域，可被观测识别。
- **推导链**:
  1. [F8] 演绎 → AIC 是毫秒脉冲星的一条形成起源，构成独立于核心坍缩的通道。
  2. [F9] 演绎 → AIC 残骸的坍缩后演化具有特定的旋转、磁场和热结构特征。
  3. [F1] 演绎 → 核心坍缩超新星是另一条独立的中子星形成通道，其诞生属性由前身星坍缩物理决定。
  4. [F2] 归纳 → 不同形成通道的前身星物理不同（白矮星吸积 vs. 大质量恒星核心坍缩），因此诞生属性（自转、磁场、热结构）的联合分布应不同。
  5. 由步骤 2（AIC 残骸有特定三维结构）与步骤 4（通道不同→分布不同）演绎 → AIC 产物在 (P, B, 热结构) 空间中应占据一个可区分的独立区域。
  6. 结论 → 存在一个可被观测识别的"AIC 脉冲星岛"，与核心坍缩脉冲星及经典再循环毫秒脉冲星在三维参数空间中分离。
- **预期新颖性**: 将 AIC 通道从"毫秒脉冲星起源"的定性说法（F8）推进为可在三维参数空间中被定位并证伪的定量预言。
- **可证伪点**: 若在足够完整的脉冲星样本中，无法在 (P, B, 热结构) 空间识别出与核心坍缩群体统计分离的子群，则 AIC 作为可观测独立通道的假设被削弱。

## H3
- **假设陈述**: 电子俘获超新星（EC-SN）产生的中子星 natal kick 速度显著低于铁核坍缩超新星产生的中子星，因此源自 EC-SN 的宽距双脉冲星群体的空间速度分布应系统性地偏向低速端。
- **推导链**:
  1. [F3] 演绎 → 核心坍缩超新星中，中子星因物质不对称抛射和中微子辐射获得 natal kick。
  2. [F5] 演绎 → 电子俘获超新星是产生 natal kick 的另一条独立通道，并可形成宽距双脉冲星。
  3. [F4] 归纳 → 踢速度和诱导自转依赖于前身星的坍缩物理，可通过前身星模拟研究；不同前身星类型（铁核 vs. ONe 白矮星核）的坍缩动力学存在本质差异。
  4. 由步骤 1、2、3 演绎 → 两条通道的不对称抛射/中微子辐射物理不同 → 预期 natal kick 幅度存在系统性差异。
  5. [F5] 再次演绎 → 宽距双脉冲星是 EC-SN 通道的产物标志，其系统速度保留了 natal kick 信息。
  6. 结论 → 宽距双脉冲星群体的空间速度应系统性低于来自铁核坍缩的孤立脉冲星群体。
- **预期新颖性**: 与胜出方案 2（用偏心率区分共同包层 vs. 连续超新星通道）正交——本假设用空间速度区分 EC-SN 与铁核坍缩两种不同物理的爆发通道。
- **可证伪点**: 若通过 Gaia/脉冲星计时测得的宽距双脉冲星空间速度分布与铁核坍缩孤立脉冲星无显著差异（或反而更高），则 EC-SN 产生较低 natal kick 的假设被推翻。
