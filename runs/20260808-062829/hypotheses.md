# 候选假设

## H1
- 假设陈述: 磁星的强磁场并非由诞生时的快速自转通过对流发电机（convective dynamo）产生，而是由不依赖初始快速自转的机制（如吸积诱导过程中的差动旋转或热对流）放大生成；因此新诞生的磁星应表现为慢速旋转者，而非快速旋转者。
- 推导链:
  1. [F8] 归纳 → 观测上缺乏磁星以快速旋转中子星诞生的证据；含磁星的超新星遗迹未显示预期的动能过剩。
  2. [F7] 归纳 → 磁星形成机制本身仍是理论挑战，缺乏坚实基础。
  3. [F9, F10] 演绎 → 磁星形成渠道开放，包含孤立大质量恒星核心坍缩与双星相互作用（如吸积诱导坍缩 AIC）等多条路径；AIC 路径可产生强磁场的快速旋转白矮星残骸，暗示磁场放大可在非经典快速自转条件下发生。
  4. [F1] 演绎 → 中子星诞生自转等属性的观测信息本就不足，无法用"未测到快速自转即否定"简单回避。
  5. 结论 → 若磁星普遍由非快速自转依赖的机制获得强磁场，则新诞生磁星应表现为慢速旋转，且其超新星遗迹不呈现快速自转中子星所预期的动能过剩——这与 F8 的观测一致并作出进一步可检验预测。
- 预期新颖性: 将磁星强磁场的起源从"快速自转 + 发电机"这一经典范式，转向"非快速自转依赖"的替代机制（如 AIC 或后诞生差动旋转），并给出可直接观测证伪的自转预测。
- 可证伪点: 若在未来观测中发现新诞生磁星普遍具有毫秒级快速自转（例如通过超新星遗迹中磁星早期自转周期的直接测量），或其遗迹呈现与快速旋转注入一致的动能过剩，则该假设被推翻。

## H2
- 假设陈述: 磁星至少通过两条物理上可区分的通道形成——孤立大质量恒星的核心坍缩超新星与双星相互作用（包括吸积诱导坍缩）——因此应存在两类在运动学或环境上可区分的磁星子群。
- 推导链:
  1. [F9] 归纳 → 磁星形成渠道仍为开放问题，文献明确列举孤立大质量恒星核心坍缩与双星相互作用等多条可能路径。
  2. [F10] 演绎 → AIC 被具体提出为磁星形成的一个可行通道，其产物（快速旋转、强磁场白矮星残骸）在物理初值上不同于孤立大质量恒星核心坍缩产物。
  3. [F8] 归纳 → 含磁星的超新星遗迹未显示统一预期的动能过剩模式，暗示并非所有磁星共享同一种诞生能量注入方式。
  4. [F11] 演绎 → 通过脉冲星运动轨迹回溯至超新星遗迹几何中心的方法（PSR J0002+6216 → CTB 1）已被验证，提供了将磁星与其诞生环境关联的可行观测手段。
  5. 结论 → 若磁星确实由至少两条物理不同的通道形成，则在足够大的磁星样本中应可识别出两个在空间速度分布、宿主遗迹形态或前身星环境上统计可区分的子群（例如：一群与典型大质量恒星遗迹关联，另一群与 AIC 特征环境或双星遗迹关联）。
- 预期新颖性: 将"磁星形成渠道开放"这一笼统表述转化为可通过磁星样本的运动学与遗迹环境聚类分析加以检验的双通道（或多通道）假说。
- 可证伪点: 若对大量磁星进行高精度天体测量（如 VLBA）和遗迹环境分析后，发现所有磁星在空间速度、宿主遗迹形态和前身星环境上构成统计上单一、不可分的总体，则该多通道假设被削弱乃至推翻。

## H3
- 假设陈述: 双中子星至少通过两条不同的形成通道产生——共同包层抛射通道与连续 II 型超新星爆炸通道——因此双中子星群体中应同时存在近圆轨道与显著偏心轨道两类系统。
- 推导链:
  1. [F4] 归纳 → 双中子星被认为在演化中至少经历一次共同包层阶段。
  2. [F5] 演绎 → 三维流体动力学模拟已成功实现共同包层抛射并导致双中子星形成，确立了 CE 通道在数值上的可行性。
  3. [F6] 归纳 → 双中子星亦可通过双星系统中连续的 II 型超新星爆炸形成，这是另一条独立的形成通道。
  4. [F12] 演绎 → 脉冲星诞生时的踢速度和前身星参数高度依赖于多维概率密度函数，说明第二次超新星爆炸的不对称踢可在双中子星系统中留下显著的轨道偏心率印记。
  5. [F1] 演绎 → 中子星形成参数（包括空间速度、踢速度）的观测信息仍不足以约束理论，意味着当前观测样本可能尚未揭示全部形成通道的印记。
  6. 结论 → 若 CE 通道与连续 SN 通道均真实运作，则 CE 通道倾向于产生经潮汐与包层抛射后近圆化的紧密双中子星，而连续 SN 通道中第二次超新星的不对称踢可产生显著偏心率；因此双中子星群体中应同时存在近圆与显著偏心的系统，且二者比例可约束两通道的相对贡献。
- 预期新颖性: 将双中子星的两条独立形成通道（CE 与连续 SN）转化为可通过轨道偏心率分布直接检验的群体预测，并为利用未来引力波或脉冲星巡天数据约束通道相对贡献提供框架。
- 可证伪点: 若未来完整的双中子星样本（通过脉冲星巡天或引力波观测）显示所有系统的轨道偏心率均接近于零（即全部为近圆轨道），则连续 II 型超新星爆炸通道作为重要形成路径的假设将被严重质疑乃至推翻。
