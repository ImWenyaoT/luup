# 候选假设

## H1
- **假设陈述**: 将活动区磁场参数的多变量时间序列经对比学习提取的演化特征，作为二级判别器叠加于单时刻快照分类器之上，可在不降低召回率的前提下将虚警率降低至少 30%，从而打破单时刻模型中召回率与虚警率的负相关权衡。
- **推导链**:
  1. [F1] 归纳 → 单时刻磁图快照无法捕捉磁场演化动态，构成现有模型的信息瓶颈。
  2. [F3] 演绎 → 已有工作证明：对连续 HMI 磁图时间堆栈使用 CNN 提取时序特征的混合两阶段架构，能有效降低虚警率——说明"时间维度特征"是降低虚警的可行路径。
  3. [F2] 演绎 → 多变量时间序列经对比学习预处理后，耀斑预测性能提升，说明对比学习能有效压缩时序演化信息为可分特征。
  4. [F6] 演绎 → 区间基时间序列分类器已能在保持有价值预测的同时高精度地识别非耀斑实例，表明时序建模对"排除非耀斑"（即降虚警）具有结构性优势。
  5. [F5] 归纳 → 时序动态中的异常模式具有预测意义，进一步佐证：演化特征中蕴含区分"真阳性前兆"与"静态高险但非耀斑态"的信号。
  6. 结论 → 若将对比学习提取的多变量时序演化特征作为第二级判别器，对单时刻模型的高风险输出做二次过滤，则可在保留召回率（一级已捕获大部分耀斑事件）的同时，利用时序演化信息剔除静态假阳性，从而打破召回率-虚警率的权衡。
- **预期新颖性**: 首次将对比学习时序特征与单时刻快照模型组成显式级联架构，并定量分离"召回贡献"与"虚警过滤贡献"于两个独立模块。
- **可证伪点**: 在标准 HMI 数据集上，若级联模型的 ROC 曲线下面积（AUC）与 Precision-Recall 曲线下面积未显著优于单时刻基线（p > 0.05），或虚警率降幅 < 10%，则该假设被证伪。

## H2
- **假设陈述**: 使用深度状态空间模型（SSM）对活动区多时刻磁图序列建模长程时间依赖，可将 M/X 级耀斑的有效预测窗口从当前主流的 24 小时拓展至 72 小时，同时保持召回率不低于 0.85。
- **推导链**:
  1. [F13] 演绎 → 论文明确指出现有端到端学习方法难以建模太阳图像中的长程时间依赖关系，这是长程预测的核心瓶颈。
  2. [F8] 演绎 → FLARE-SSM 模型已证明深度状态空间模型配合影响平衡损失可用于 72 小时耀斑预测，并处理严重类别不平衡——说明 SSM 架构在长程预测任务上已有可行性验证。
  3. [F1] 归纳 → 单时刻快照无法捕捉演化动态，意味着越长的预测窗口越需要依赖历史演化信息而非瞬时状态。
  4. [F2] 归纳 → 多变量时间序列的预处理与对比学习可提升预测性能，佐证时序信息的系统性利用对预测有增益。
  5. [F3] 演绎 → 混合两阶段架构利用时间堆栈降低虚警率，表明时序信息在减少"过早误报"方面也有作用——这对长程预测尤为关键（长窗口内假阳性累积更严重）。
  6. 结论 → 若以 SSM 替代现有端到端模型中的 CNN/RNN 骨干，显式建模活动区磁场的长程时间依赖，则可在 72 小时窗口内维持高召回率，因为 SSM 能选择性保留远距离前兆信号而衰减无关噪声。
- **预期新颖性**: 将 SSM 的长程依赖建模能力与耀斑预测的物理时间尺度（磁自由能积累过程 ~数天）直接对应，提出"SSM 隐状态衰减时间常数应与耀斑前兆演化的特征时间尺度匹配"这一可检验设计原则。
- **可证伪点**: 若 SSM 模型在 48–72 小时预测窗口内的 Heidke Skill Score (HSS) 或 True Skill Statistic (TSS) 不显著优于使用相同数据窗口的 CNN/LSTM 基线（p > 0.05），或召回率低于 0.80，则该假设被证伪。

## H3
- **假设陈述**: 在光球层以上、低日冕以下的三维外推磁场界面区域（由 WGM 方法标定的最佳预测高度范围），对时间序列磁诊断量进行异常检测，可识别出单靠光球层单时刻磁图无法发现的"隐伏型"前耀斑态，从而将当前模型遗漏的虚警案例中的至少 20% 重新归类为真阳性或确认的非耀斑态。
- **推导链**:
  1. [F7] 演绎 → WGM 方法应用于三维外推磁场配置，可在光球层与低日冕之间的界面区域识别最佳耀斑 onset 时间预测高度范围——说明关键预测信号可能不在光球层本身。
  2. [F1] 归纳 → 单时刻光球层磁图难以捕捉磁场演化动态，且其信息局限于光球层二维投影。
  3. [F5] 演绎 → 时间序列异常值检测可提高耀斑预测可靠性，说明时序动态中的异常模式具有预测意义。
  4. [F4] 归纳 → 极区磁场等全局特征可补充局部活动区数据以提升预测，证明单一局部信息源（如仅光球层活动区快照）存在结构性不足。
  5. [F11, F12] 归纳 → 归因方法和可解释 AI 研究表明，模型关注区域与物理量之间存在可量化关系，但当前模型主要聚焦光球层磁图——暗示光球层以上的诊断信息被系统性忽略。
  6. 结论 → 若在 WGM 标定的最佳高度范围内，对三维外推磁场的时间序列诊断量（如水平磁场梯度演化）执行异常检测，则能发现光球层单时刻磁图中不可见的"隐伏"前兆信号，从而解释并改善当前模型中部分虚警（实为未被识别的真前兆）与漏报。
- **预期新颖性**: 将"虚警来源"重新解释为"光球层以上前兆信号被遗漏"，提出虚警率问题不仅是分类器问题，更是观测维度（高度）不足的问题。
- **可证伪点**: 若在 30 个以上活动区样本中，三维外推磁场界面区域的时序异常检测未能将当前虚警案例中 ≥ 15% 重新归类（即界面区域信号与光球层信号在预测能力上无统计显著差异，DeLong 检验 p > 0.05），则该假设被证伪。
